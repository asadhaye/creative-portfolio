# asadhaye.com

Personal brand and portfolio website for Muhammad Asad Haye.

## Positioning

**Digital Growth Strategist & Product Builder**

The site tells a career story spanning community work, international sales, operations, research, entrepreneurship, marketing, teaching, e-commerce, digital growth, technology and AI.

## Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- Lucide React

## Local development

```bash
pnpm install
pnpm dev
```

Then open `http://localhost:3000`.

## Architecture

- `app/` — routes, layout and global styles
- `content.ts` — factual timeline, capabilities, work and principles
- `AGENTS.md` — permanent implementation rules for coding agents

## Design direction

Editorial technology: premium, restrained, human and technically capable. The experience must remain strong without WebGL.
