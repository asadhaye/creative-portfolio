# ASADHAYE.COM — DEVELOPMENT RULES

## Product
Personal brand and portfolio website for Muhammad Asad Haye.

## Positioning
Digital Growth Strategist & Product Builder.

## Design
Editorial technology: premium, minimal, human, experimental but restrained.

## Never
- Invent experience, clients, metrics, awards or testimonials.
- Turn the site into a generic freelancer or agency template.
- Make WebGL or animation required for core content.
- Sacrifice accessibility or performance for visual effects.
- Use excessive gradients, glassmorphism or dashboard-style cards.

## Architecture
- Next.js App Router + TypeScript.
- Server Components by default.
- Client Components only when interaction requires them.
- Keep factual content separated from presentation components.
- Prefer simple, composable components.

## UX
- Mobile is intentionally designed, not merely a shrunken desktop.
- Every interactive element must work without hover.
- Respect prefers-reduced-motion.
- Core content must remain usable if JavaScript enhancements fail.

## Content
The approved project charter and timeline are the source of truth. If a factual detail is uncertain, flag it instead of guessing.

## Visual direction
Quietly impressive. Editorial technology. The website should feel like the digital headquarters of a marketer, builder and entrepreneur—not a resume rendered in a browser.
