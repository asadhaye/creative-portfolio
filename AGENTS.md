# ASADHAYE.COM — DEVELOPMENT RULES

## Product
Personal portfolio and professional brand website
for Muhammad Asad Haye.

## Positioning
Digital Growth Strategist & Product Builder.

## Design
Editorial technology.
Premium.
Minimal.
Human.
Experimental but restrained.

## Never
- invent experience
- invent metrics
- invent clients
- add generic portfolio filler
- make WebGL mandatory
- sacrifice accessibility for animation
- overuse gradients
- use excessive glassmorphism
- create generic SaaS UI

## Architecture
- Next.js App Router
- TypeScript
- Server Components by default
- Client Components only when interaction requires them
- Content separated from components

## Performance
- semantic HTML
- optimized images
- progressive enhancement
- no unnecessary third-party scripts
- no blocking animation

## Responsive
Design mobile intentionally.
Never simply shrink desktop.

## Content
The factual timeline is authoritative.
Do not rewrite historical facts without approval.
